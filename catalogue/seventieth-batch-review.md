# Japanese mountain, island and inland cargo trials

Reviewed 3 November 2026. Eight previously unlisted dispatch sites. The Hakuba and Fukuoka trials each document distinct freight loaded for the return flight, supporting two physical origins per route. The other four records retain only the documented dispatch sites. All coordinates represent approximate localities; the reports do not establish present operations.

- [Kurobishi forest road food dispatch](https://www.mlit.go.jp/common/001306901.pdf): The report describes five round trips across the route. This record represents the lower dispatch site, not five facilities.
- [Happo-Ike Sanso return-cargo site](https://www.mlit.go.jp/common/001306901.pdf): The lodge counts because the project reports cargo departing from it on the return leg. No ongoing waste service is established.
- [Karatomari Port island freight trial](https://www.mlit.go.jp/common/001344718.pdf): The source reports three round trips for the route. It does not confirm routine port service.
- [Genkai Island seafood return dispatch](https://www.mlit.go.jp/common/001344718.pdf): The documented handling site was beside the heliport; the map marker is an island locality reference.
- [Odaka Post Office inter-office trial](https://www.mlit.go.jp/common/001301646.pdf): This is the dispatch end of a postal trial, distinct from the research flight-test campuses in the same prefecture.
- [Wake interchange park shopping trial](https://www.mlit.go.jp/common/001301646.pdf): The project used a route mainly over the river. Receiving addresses and flight observers are not additional sites.
- [Urayama Dam recreation-supply dispatch](https://www.mlit.go.jp/common/001306908.pdf): This experiment preceded the separate 2023 Nakatsugawa landslide deliveries. The destination campsite is not counted.
- [Higashi-Innai community hall delivery trial](https://aeronext.co.jp/news/usa_poc/): Although the project evaluated roadside-station logistics, the documented departure location was a community hall. Both routes share one origin.

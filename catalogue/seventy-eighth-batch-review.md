# Lake Victoria and Zomba medical dispatch sites

Reviewed 4 November 2026. Tanzania joins the catalogue. The two Lake Victoria origins are one pilot with different cargo loaded at each end. All three locations describe historical activity and use locality-level coordinates.

- [Mwanza Medical Stores Department dispatch trial](https://wingcopter.com/project/tanzania-medical-delivery): This record counts the mainland dispatch site. The trial report does not establish a continuing scheduled service.
- [Nansio District Hospital sample return trial](https://wingcopter.com/project/tanzania-medical-delivery): The hospital counts separately from Mwanza because the operator documents a new payload departing from the island. The marker identifies the town, not a surveyed landing pad.
- [Matawale Hospital polio vaccine dispatch](https://www.unicef.org/malawi/stories/drones-fly-stop-polio-malawi): Magomero is documented as the receiving facility. The wider network described in the article is not counted as additional dispatch sites.

# Japan: seven documented dispatch origins

Reviewed 4 November 2026. Historical activity only. All map points identify approximate localities.

- [Miwa Post Office logistics rehearsal](https://www.mlit.go.jp/common/001215391.pdf): The public demonstration was stopped after an aircraft anomaly. The report attributes successful validation to earlier rehearsals. Only the previously unlisted postal end is added.
- [LIVIN Yokosuka island delivery dispatch](https://drone.rakuten.co.jp/cases/20190704/): The mainland store counts once. The seasonal service report does not establish current dispatches.
- [Lawson Minamisoma-Odaka delivery dispatch](https://drone.rakuten.co.jp/cases/20171031/): The retailer is distinct from Odaka Post Office. The approximate locality marker is not a building or launch coordinate.
- [MaxValu Ugata island supply dispatch](https://drone.rakuten.co.jp/cases/20210106/): The island is a receiving location. Repeated flights from the same supermarket count as one dispatch site.
- [Sarukura-so mountain supply dispatch](https://drone.rakuten.co.jp/cases/other/): One lodge dispatched both routes. This is a separate origin from the Kurobishi and Happo-Ike trial.
- [Otaki Onsen roadside station delivery trial](https://drone.rakuten.co.jp/cases/20221220/): The dam office received the loads. The named origin distinguishes this route from the Urayama Dam trial.
- [Prologis Park Ichikawa 3 delivery trial](https://www.post.japanpost.jp/notification/pressrelease/2022/00_honsha/0111_01_01.pdf): The rooftop heliport received the deliveries. The dispatch site was the parking lot in Ichikawa.

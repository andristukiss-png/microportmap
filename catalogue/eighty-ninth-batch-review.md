# Twinwoods flight-test centre

Reviewed 5 November 2026. One historical research facility brings the catalogue to 554 records across 53 countries.

Blue Bear's 29 August 2019 report identifies Twinwoods as the site of an Agristart UAV test with remote control from Kingston University and a local safety pilot. The publication date is not asserted as the flight date. Cranfield's January 2020 report independently identifies the Twinwoods test site near Oakley as a separate end of the NBEC corridor.

Duplicate review covered all 553 existing records and aliases Blue Bear, Twinwoods, Bedford and NBEC. The existing Cranfield Drone Flight Arena is a separate facility. Neither Kingston's remote control position nor the corridor is counted as another site. Westcott DTDC was considered but not added because of its overlap with the existing Skyports Westcott hub.

The marker is a rounded Oakley locality reference, not a flight boundary or launch coordinate. Current operations, access and flight permission remain unverified.

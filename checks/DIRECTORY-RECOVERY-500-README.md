# Directory recovery batch

Run `node checks/directory-recovery-500.cjs` from the bundle root. Ten sequences for each original project yield 500 checks using real directory/search/JSON scripts in the existing controlled DOM/VM harness. Delayed requests, timeouts and object-URL allocation failures are synthetic. Each successful JSON download is checked against exact original records. Full-catalog reset also checks name ordering.

All 500 pass. No application source change or deployment. Regression suites pass. This batch does not verify actual mobile rendering, live online map tiles, external research accuracy or submission delivery.

# Cluster recovery checks

Run `node checks/cluster-recovery-500.cjs` from the bundle root. Ten behaviors per original project provide 500 recorded checks. The real atlas script runs inside controlled DOM and Leaflet doubles reused from the cluster harness. Synthetic country/category labels, names containing markup and missing coordinates are test fixtures only. Original data is unchanged.

All 500 passed; no production source change or deployment was needed. The batch verifies chooser escaping and accents, exact search, country/type URL synchronization, empty-state recovery, fallback drawer focus, unmapped record retention and stale marker removal. It does not establish mobile rendering, live online tile availability or research accuracy.

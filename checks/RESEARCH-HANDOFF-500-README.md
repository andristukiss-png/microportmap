Run `node checks/research-handoff-500.cjs` from the bundle root. Five correction sequences and five quality-export sequences for each original project produce 500 checks. Real scripts run in existing controlled DOM/VM harnesses. Unusual references are URL encoded before being passed to the raw-query prefill harness. Faulty record fields, duplicate IDs and download failures are isolated synthetic fixtures.

All 500 passed. No app source changes or deployment. Correction reports remain locally prepared and are not sent anywhere. URL format acceptance does not establish source accuracy. Mobile visuals, online map tiles and independent research remain unverified.

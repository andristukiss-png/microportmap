# Atlas history sequences

Run `node checks/atlas-history-500.cjs` from the bundle root. Ten route-transition sequences per original project yield 500 cases. The real atlas script handles controlled popstate events in the existing DOM/VM harness. Known, unknown and absent project references are mixed while retaining a valid query/country/category view. Drawer identity, focus, background inert state, scroll lock and final filter retention are checked.

All 500 passed. An unset mock style is normalized to the browser-equivalent empty string in the assertion. No application source change or deployment. Actual browser history traversal, mobile visuals, online tiles and independent research are not established by this batch.

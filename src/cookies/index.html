What browser storage and external map technologies this website uses.

Last updated 21 October 2026 · Early-stage website

Legal NoticePrivacy PolicyCookie PolicyTerms of Service

Current tracking

Our present website code does not install analytics, marketing, advertising or profiling cookies. Hosting and optional third-party resources may use technical cookies or similar technologies subject to their own policies. We will update this document if tracking is later introduced.

Local map preference

The website stores a choice in your browser using local storage key microportmap_map_preference_v1. This remembers whether you requested the interactive external map. It is not an advertising cookie. It can be changed using the Map privacy settings link in the homepage footer or removed from browser site data.

Optional third-party map resources

The built-in world view works without external map requests. Enabling the interactive map lets the browser download a Leaflet script and stylesheet from unpkg and map tiles from OpenStreetMap; their servers receive IP and request information. Providers may set necessary technical storage according to their policies. OSM privacy · OSM tile policy.

How to change consent

Choose “Use basic map” to keep external map resources unloaded, or “Enable interactive map” to activate them. The choices are equivalent in prominence, and neither enables marketing or analytics. You can change your choice later. Disabling cannot reverse network requests already made, but prevents future map-tile loading from this website.

Local bookmarks

Saved project identifiers are stored locally under microportmap_bookmarks_v2 and are not sent to the website.
